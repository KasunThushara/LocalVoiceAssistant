Q: Introduce yourself / Introduce this demo / What does this demo do / Tell me about this demo / What is this demo
A: This demo showcases an intelligent real-time Q&A platform based on reSpeaker. It uses a 4-microphone array to detect wake words and record 5-second queries for speech-to-text conversion. Queries are processed by locally deployed Llama 3 with RAG architecture, then converted to speech through local TTS engine. The solution works on NVIDIA Jetson, x86, and Linux systems for secure automated human-computer interaction.
